# Antara Studios — Interior Design POC

A fully interactive, branded interior design application built for [Antara Studios](https://antarastudios.com) — Bangalore's premier interior design studio.

## 🏛️ What It Does

A step-by-step room design experience:
1. **Style Preferences** — Choose from 8 curated design aesthetics
2. **Room Selection** — Pick rooms to design (Living, Kitchen, Dining, Bedroom, Bathroom, Pooja Room)
3. **Room Designer** — Customise every wall zone, floor, ceiling with real-time 3D preview
4. **Moodboard Summary** — Full room-by-room design plan with palette strips and comparison tool

## 🎨 Brand

Built using Antara Studios' exact brand language:
- Colors: `#E9B9A3` (blush-gold) · `#3B2D35` (plum) · `#1A1714` (dark)
- Fonts: Raleway + Golos Text
- Tone: Dark luxury, warm editorial
